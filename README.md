# analytical lab
 This repo contains a few scripts used in the analytical chemistry lab at a high throughput scale.

 1. The basic_ file creates a coordinate mapping logic for some 96 wells plates.
 2. The auto_ markdown file generates a report of the system suitability of an 8 peptides method, critical in deciding whether the whole setup is ready for a full plate analysis
 3. The blood collection file creates linear regression curves between the peptides concentrations and the area counts.
